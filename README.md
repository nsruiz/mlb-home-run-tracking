## Project Overview

This repository showcases an end-to-end sports data pipeline that
collects MLB play data and transforms it into structured payloads for use within a 3-D Blender scene to generate animated home
run highlights.

The system in production runs automatically on a daily basis during the Major League Baseball season using AWS (Lambda, S3) and
cron jobs. Player info, statistics, video, and tracking data from the previous day's longest home runs are collected, reformatted, and deployed in a Blender Python script to update a 3-D "world." 

The resulting video asset is then showcased in a youth-focused sports app and distributed via social media.

## What This Demo Emphasizes

This project focuses on:
- structuring and transforming sports tracking data
- designing clean data contracts between systems
- automating visual outputs via code
- building reproducible pipelines from real-world data

## Repository Structure

home_run_pipeline/:
  Data collection and transformation logic

data/input/:
  Frozen sample inputs (MLB play data, team metadata)

data/output/:
  Generated Blender-ready payload

blender_demo/:
  bpy script that updates a base Blender scene and renders output

media_output_samples/:
  Example rendered highlight video generated by the demo

run_demo.py:
  Entry point that drives the data transformation pipeline

## Notes on Production Differences

In production, this pipeline:
- makes live queries to the MLB API
- retrieves and processes MLB broadcast video
- runs on a daily automated schedule via AWS Lambda and Windows Task Scheduler 

These elements are replaced here with static artifacts and placeholders
to keep the demo lightweight and self-contained.
